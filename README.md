# до звонка (do-zvonka)

Приложение для отслеживания оставшегося времени до конца урока или перерыва. Название в коде: `do_zvonka`, в интерфейсе: **до звонка** (все строчными буквами).

## Особенности

- 🌙 **Тёмная тема** с фиолетовыми акцентами (Material 3)
- 🕐 **Таймер в реальном времени** — показывает оставшееся время до конца текущего урока, обычной перерыва или большой перемены
- ⚙️ **Настройка расписания** — при первом запуске запрашивает:
  - Время начала занятий
  - Длительность одного урока
  - Длительность обычного перерыва
  - Количество уроков в день
- 🍽️ **Большие перемены (обеды)** — поддержка нескольких больших перемен с настройкой:
  - После какого урока начинается
  - Длительность в минутах
  - Название (например, "обед", "большая перемена")
- 📝 **Редактор больших перемен** — удобный интерфейс для добавления/редактирования/удаления
- 💾 **Сохранение настроек** — данные хранятся локально (SharedPreferences)
- 📱 **Виджет для рабочего стола** — показывает "осталось XX:XX" и тип периода (урок/перемена/большая перемена)
- 🎨 **Дизайн** — заголовки шрифтом **Unbounded**, основной текст — **Onest**, весь интерфейс на русском в нижнем регистре

## Скриншоты

*Приложение показывает:*
- Круговой таймер с оставшимся временем (цвет зависит от типа периода)
- Текущий период (урок N, перемена N, большая перемена)
- Время окончания текущего периода
- Список следующих звонков (до 4 периодов)
- Карточку с информацией о расписании (включая количество больших перемен)

## Установка и запуск

### Требования
- Flutter SDK 3.14+
- Android Studio / Android SDK (для сборки APK)
- Устройство или эмулятор с Android 5.0+

### Запуск в режиме разработки

```bash
# Клонирование репозитория
cd do-zvonka

# Установка зависимостей
flutter pub get

# Запуск на подключенном устройстве/эмуляторе
flutter run
```

### Сборка APK

```bash
# Debug APK
flutter build apk --debug

# Release APK (оптимизированный)
flutter build apk --release
```

Готовый APK будет в `build/app/outputs/flutter-apk/`.

### Установка виджета

1. Долгое нажатие на пустое место на рабочем столе Android
2. Выберите "Виджеты"
3. Найдите "до звонка" и перетащите на рабочий стол
4. Виджет автоматически обновится при изменении времени

## Android Widget (Виджет)

Виджет реализован через `home_widget` пакет:

- **Конфигурация**: `android/app/src/main/res/xml/do_zvonka_widget_info.xml`
- **Лейаут**: `android/app/src/main/res/layout/do_zvonka_widget.xml`
- **Провайдер**: `android/app/src/main/kotlin/com/dozvonka/do_zvonka/DoZvonkaWidgetProvider.kt`

Виджет обновляется:
- Автоматически каждые 30 минут (Android system)
- При каждом изменении настроек в приложении
- При возвращении приложения из фона

## Логика больших перемен

Большие перемены вставляются в расписание **после указанного урока** и **заменяют собой обычный перерыв** после этого урока.

Пример для 6 уроков с большой переменой после 3-го урока (30 мин):
```
Урок 1 (45 мин) → Перерыв (10 мин)
Урок 2 (45 мин) → Перерыв (10 мин)
Урок 3 (45 мин) → Большая перемена (30 мин) ← вместо обычного перерыва
Урок 4 (45 мин) → Перерыв (10 мин)
Урок 5 (45 мин) → Перерыв (10 мин)
Урок 6 (45 мин) → Конец
```

Можно настроить несколько больших перемен (например, после 2-го и 4-го уроков).
